# FlowerShop - сайт по продаже персонализированных букетов

Веб-приложение для заказа букетов. Пользователь выбирает букет из каталога или
проходит опрос для подбора букета, указывает имя, телефон, адрес и время
доставки, может применить промокод на странице оплаты. Также можно оставить
заявку на консультацию флориста. 

## Требования

- Python или Python3 должен быть установлен. Проверенная версия - 3.12.

## Быстрый старт

### 1. Виртуальное окружение

Windows, PowerShell:

```
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Linux, macOS:

```
python3 -m venv venv
source venv/bin/activate
```

### 2. Зависимости

```
pip install -r requirements.txt
```

### 3. Переменные окружения

Создайте файл .env по примеру .env.example:

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `SECRET_KEY` | да |  | Секретный ключ Django. Без него приложение не стартует |
| `DEBUG` | нет | `True` | Режим отладки. На боевом сервере выставить `False` |
| `ALLOWED_HOSTS` | нет | `127.0.0.1,localhost` | Список доменов через запятую, без пробелов |
| `CSRF_TRUSTED_ORIGINS` | нет |  | Адрес сайта. Используется для ссылок на метки в админке |


### 4. База данных

```
python manage.py migrate
```

### 5. Справочные данные

Заполнить каталог букетов и поводы для подбора:

```
python manage.py loaddata bouquets occasions
```

### 6. Учётная запись администратора

Нужна, чтобы смотреть заказы и заявки на консультацию, вести букеты, поводы и промокоды в админке:

```
python manage.py createsuperuser
```

### 7. Запуск

```
python manage.py runserver
```

Сайт откроется на `http://127.0.0.1:8000/`.


## Заказ и оплата

Регистрация не нужна: для заказа достаточно указать имя, телефон, адрес и время
доставки и согласиться с политикой конфиденциальности. После заказа открывается
страница оплаты, где можно применить промокод из админки.

**Оплата сейчас не проводится: данные карты никуда не отправляются, заказ просто
получает статус «Ожидает доставки».**


## Линтеры

Линтеры лежат в `requirements-dev.txt`, их нужно доставить отдельно от
`requirements.txt`:

```
pip install -r requirements-dev.txt
```

После этого доступны проверки, которыми пользуется CI:

```
black --check .
isort --check-only --diff .
flake8 .
```

Настройки всех трёх - в `pyproject.toml`: длина строки 119, миграции
исключены из форматирования.


## Развёртывание

На сервере в `.env` выставить `DEBUG=False`, домен в `ALLOWED_HOSTS` и адрес
со схемой в `CSRF_TRUSTED_ORIGINS`, затем собрать статику:

```
python manage.py collectstatic
```

При `DEBUG=False` Django не раздаёт статику, её должен отдавать веб-сервер из папок `staticfiles/` и `media/`.
